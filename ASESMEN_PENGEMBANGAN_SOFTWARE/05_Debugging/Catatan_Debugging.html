Laporan & Catatan Proses Debugging

Sistem Manajemen Data Mahasiswa & Transkrip Nilai (SIMAMA)

Unit Kompetensi: Melakukan Debugging (Kode Unit: J.620100.016.01)

1. Analisis Kasus Error & Penanganan Exception

Kasus 1: ValueError pada Input String Karakter ke Nilai Desimal

Pemicu: Pengguna memasukkan karakter teks (contoh: "delapan puluh") pada saat diminta memasukkan nilai tugas/uts/uas.

Pesan Traceback Asli:

ValueError: could not convert string to float: 'delapan puluh'
Solusi Penerapan Clean Code & Try-Except:

Membungkus proses input dalam fungsi input_float() di utils.py menggunakan loop while True dan blok penangkap try ... except ValueError sehingga sistem memberikan pesan peringatan bersahabat dan tidak berhenti beroperasi.

Kasus 2: sqlite3.IntegrityError Akibat Duplikasi Primary Key NIM

Pemicu: Pendaftaran mahasiswa baru dengan NIM yang sudah ada di dalam tabel database SQLite.

Pesan Traceback Asli:

sqlite3.IntegrityError: UNIQUE constraint failed: mahasiswa.nim
Solusi Penanganan:

Menangkap sqlite3.IntegrityError secara eksplisit di database.py dan mengembalikan tuple status (False, "Gagal: Mahasiswa dengan NIM sudah terdaftar!").

Kasus 3: ZeroDivisionError pada Kalkulasi Rata-rata Kelas Kosong

Pemicu: Pengguna membuka menu statistik saat basis data dalam keadaan kosong (0 baris).

Pesan Traceback Asli:

ZeroDivisionError: division by zero
Solusi Penanganan:

Pemeriksaan logika pra-kalkulasi if not daftar: return pada main.py sebelum pemanggilan fungsi agregasi matematika.

2. Prosedur Debugging Menggunakan Breakpoint (Visual Studio Code)

Untuk memastikan kalkulasi nilai berbobot bekerja secara presisi, telah dilakukan pengujian dengan fitur breakpoint:

  • Pemasangan Breakpoint (F9): Ditandai pada file 02_SourceCode/project/utils.py baris perhitungan hasil = (0.30 * tugas) + (0.30 * uts) + (0.40 * uas).
  • Menjalankan Debug (F5): Menjalankan test_kalkulasi.py dalam mode debug.
  • Pemeriksaan Variabel (Watch Window): Memeriksa nilai variabel memori saat eksekusi di-pause: tugas=85.0, uts=90.0, uas=88.0.
  • Melangkah Baris per Baris (F10 - Step Over): Memastikan nilai hasil terhitung akurat menjadi 87.7 sebelum di-return.
