Dokumen Spesifikasi Kebutuhan Perangkat Lunak

Sistem Manajemen Data Mahasiswa & Transkrip Nilai (SIMAMA)

Skema Sertifikasi: Pemrograman / Software Development (BNSP)

Nama Aplikasi SIMAMA (Sistem Manajemen Data Mahasiswa) Unit Kompetensi Mengimplementasikan Spesifikasi Program
Bahasa / Platform Python 3.10+ / SQLite 3 (CLI Console) Versi Dokumen 1.0.0 (Siap Asesmen)

1. Deskripsi Umum Sistem

SIMAMA adalah aplikasi berbasis Command Line Interface (CLI) yang dirancang untuk mengelola data akademik mahasiswa secara terpusat, mencakup identitas diri, pencatatan nilai mata kuliah (Tugas, UTS, UAS), penghitungan nilai akhir berbobot secara otomatis, penentuan predikat grade huruf (A, B, C, D, E), penentuan status kelulusan, penyajian ringkasan statistik kelas, serta operasi CRUD (Create, Read, Update, Delete) yang persisten ke basis data SQLite.

2. Kebutuhan Fungsional (Functional Requirements)

Kode Nama Fitur Deskripsi Kebutuhan
FR-01 Tambah Data & Nilai Sistem dapat menyimpan data mahasiswa baru (NIM, Nama, Jurusan, Nilai Tugas, Nilai UTS, Nilai UAS) ke basis data SQLite.
FR-02 Tampilkan Seluruh Data Sistem dapat menyajikan tabel seluruh data mahasiswa beserta nilai akhir, predikat grade, dan status kelulusan.
FR-03 Pencarian Data Mahasiswa Sistem dapat menyaring data berdasarkan kata kunci pencarian NIM, Nama Lengkap, atau Program Studi.
FR-04 Perbaruan Data (Update) Sistem dapat memperbarui data identitas maupun komponen nilai mahasiswa berdasarkan nomor induk (NIM).
FR-05 Penghapusan Data (Delete) Sistem dapat menghapus rekaman data mahasiswa dari basis data dengan konfirmasi persetujuan keamanan.
FR-06 Statistik Nilai Kelas Sistem dapat menghitung dan menampilkan rata-rata nilai, nilai tertinggi, nilai terendah, serta rasio kelulusan.
FR-07 Validasi Input Data Sistem memverifikasi format NIM alfanumerik (5-20 karakter) dan memastikan nilai akademik berada pada rentang numerik 0.0 s/d 100.0.

3. Kebutuhan Non-Fungsional (Non-Functional Requirements)

Kode Kategori Deskripsi Kebutuhan
NFR-01 Usability Antarmuka konsol memiliki navigasi menu angka yang jelas (0-6) serta format tabel ASCII yang terstruktur dan mudah dipahami.
NFR-02 Reliability & Robustness Sistem menangani kesalahan input pengguna menggunakan konstruksi try-except sehingga aplikasi tidak mengalami crash/terminasi abnormal.
NFR-03 Portability Menggunakan SQLite 3 dan Python standard library sehingga berjalan tanpa dependensi instalasi DBMS server pihak ketiga.
NFR-04 Maintainability Struktur kode modular mematuhi PEP 8 (Clean Code) dengan pemisahan entitas models.py, database database.py, dan logika utils.py.

4. Kamus Data (Data Dictionary) - Tabel `mahasiswa`

Nama Kolom Tipe Data Constraint Keterangan
id INTEGER PRIMARY KEY AUTOINCREMENT Nomor urut unik internal basis data
nim TEXT / VARCHAR(20) NOT NULL, UNIQUE Nomor Induk Mahasiswa (kunci pencarian)
nama TEXT / VARCHAR(100) NOT NULL Nama lengkap mahasiswa
jurusan TEXT / VARCHAR(50) NOT NULL Program studi / Jurusan
nilai_tugas REAL NOT NULL, CHECK (0-100) Nilai komponen tugas terbobot
nilai_uts REAL NOT NULL, CHECK (0-100) Nilai Ujian Tengah Semester
nilai_uas REAL NOT NULL, CHECK (0-100) Nilai Ujian Akhir Semester
nilai_akhir REAL NOT NULL Hasil kalkulasi formula bobot akademik
grade TEXT NOT NULL, DEFAULT 'E' Predikat huruf mutu (A, B, C, D, E)
status TEXT NOT NULL, DEFAULT 'TIDAK LULUS' Status kelulusan (LULUS / TIDAK LULUS)
